# Transformando curiosidade em código


Sou Wilton Soares, mineiro de Uberlândia e apaixonado por tecnologia desde sempre. Aos 44 anos, decidi mergulhar de vez nesse universo e hoje sigo firme na graduação em Análise e Desenvolvimento de Sistemas pela Estácio.
Minha missão é simples: aprender, evoluir e compartilhar. Cada linha de código que escrevo é um passo rumo a um futuro onde ideias se tornam soluções reais. E, claro, minha linguagem favorita para dar vida a essas ideias é o Python , pela sua versatilidade e poder.
Aqui no GitHub você vai encontrar minha caminhada registrada em projetos, experimentos e desafios que refletem não só aprendizado, mas também a vontade de construir algo maior.
